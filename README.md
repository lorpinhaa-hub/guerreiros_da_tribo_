# 💚 Guerreiros da Tribo - Guarani F.C.

Aplicativo oficial da torcida Guerreiros da Tribo.

## 🚀 Como rodar o projeto

```bash
# Instala as dependências
npm install

# Copia o arquivo de variáveis de ambiente
cp .env.example .env

# Edita o .env com sua chave da API Base44
# VITE_BASE44_KEY=chave_aqui

# Inicia o servidor de desenvolvimento
npm run dev
